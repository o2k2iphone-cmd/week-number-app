# 週番確認アプリ

iPhoneとWindows 11で使う、インストール不要の静的PWAです。OpenAIなどのAI API、APIキー、外部ライブラリは使いません。週番の計算とTSV生成は端末内のJavaScriptだけで行います。

## 使い方

- 起動すると今週の「31週」「202631」「9月21日（月）開始」のような情報を表示します。
- **週番 → 日付**：`2025年25週`、`2025年度第25週`、`202525`を入力すると開始日を表示します。入力中に自動で更新されます。
- **日付 → 週番**：日付を選ぶと`202525（25週）`のように表示します。
- **一括TSV**：開始週と終了週を入力して「TSVを生成」→「TSVをコピー」。Excelで貼り付け先の左上のセルを選び、貼り付けます。最大520週までの、月曜日の日付だけを並べた1行の横持ちTSVを作成できます。画面を広げるボタンと、対応ブラウザでは全画面ボタンもあります。
- iPhoneの週番入力欄では、標準キーボードのマイクを使って音声入力できます。読み上げ対応ブラウザでは「読み上げ」ボタンも表示します。

ショートカット用のURLとして、`?week=202525`または`?date=2025-08-11`も使えます。例：`https://ユーザー名.github.io/リポジトリ名/?week=202525`。

## 週番の計算規則

1. その年の3月1日を含む月曜～日曜の週の月曜日を、第1週の開始日とします。
2. 以後、月曜日ごとに週番号を1増やします。
3. 次年度の第1週が始まる前日までは、同じ年度番号を使用します。年度によって52週または53週です。
4. 表記は年度4桁と週2桁をつなげた6桁です。固定の週番表は使いません。

検算値：

| 内容 | 結果 |
| --- | --- |
| 2026年度 第1週 | 2026/2/23 |
| 2026年度 第31週 | 2026/9/21 |
| 2026/9/24 | 202631（31週） |
| 2025年度 第1週 | 2025/2/24 |
| 2025年度 第25週 | 2025/8/11 |
| 2021年度 第1週 | 2021/3/1 |

## GitHub Pagesに公開

1. GitHubでリポジトリを作り、このフォルダの**中身をすべて**リポジトリの最上位に配置します。`index.html`が最上位にある状態です。ビルド作業は不要です。
2. リポジトリの **Settings → Pages → Build and deployment** で、**Source: Deploy from a branch**、ブランチを`main`、フォルダを`/(root)`にして保存します。
3. 表示された公開URL（通常は`https://ユーザー名.github.io/リポジトリ名/`）を開きます。PWAのオフライン利用にはHTTPSの公開URLを使ってください。

リンク・アイコン・Service Workerは相対パスで指定しているため、リポジトリ名を含むGitHub PagesのURLで動作します。初回は通信が必要ですが、ページを一度開いてService Workerが登録された後は、保存済みの画面と計算機能をオフラインで使えます。更新後も古い表示が残る場合は、オンラインでページを再読み込みしてください。

参考：[GitHub Pagesの公開元設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)、[GitHub PagesのURL形式](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

## iPhoneのホーム画面・ショートカット

1. iPhoneの**Safari**で公開URLを開きます。
2. Safariの共有メニューから**ホーム画面に追加**を選びます。表示される場合は**ウェブアプリとして開く**をオンにし、**追加**を押します。以後はホーム画面のアイコンからすぐに今週の週番を確認できます。
3. ショートカットから開く場合は、ショートカットアプリで新規ショートカットを作り、公開URLを指定する**URL**アクションと**URLを開く**アクションを追加します。特定の週を開く場合はURLに`?week=202525`を付けます。
4. アクションボタン対応iPhoneなら、**設定 → アクションボタン → ショートカット**で作成したショートカットを選択します。

音声入力はアプリ独自の音声認識ではなく、iPhone標準キーボードの機能です。読み上げは端末・ブラウザで利用できる場合だけ表示されます。

参考：[Safariからホーム画面に追加](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)、[アクションボタンの設定](https://support.apple.com/ja-jp/guide/iphone/iphe89d61d66/ios)、[ショートカットでURLを開く](https://support.apple.com/en-qa/guide/shortcuts/apd621a1ad7a/ios)

## Windows 11で小さく使う

Edgeで公開URLを開き、アドレスバーのアプリのインストールアイコン、またはメニューの**アプリ → このサイトをアプリとしてインストール**から追加できます。独立したウィンドウで開くので、幅を小さくしてExcelやTableauの横に置けます。一括変換では必要なときだけ「広く表示」または「全画面」を使ってください。

参考：[Microsoft EdgeでWebアプリをインストールする](https://support.microsoft.com/ja-JP/edge/install-manage-or-uninstall-apps-in-microsoft-edge)

## ローカルで確認・テスト

フォルダ内の`index.html`をダブルクリックしても、週番の確認・変換を使えます。ただし、ホーム画面へのPWA追加とオフライン保存には、GitHub PagesのHTTPS公開URL（またはローカルサーバー）が必要です。

Node.jsがある場合、次のコマンドでも動作確認できます。追加パッケージのインストールは不要です。

```text
node scripts/dev-server.mjs
```

ブラウザで`http://127.0.0.1:4173/`を開きます。計算のテストは次で実行します。

```text
node --test
```

テストでは上の検算値、年度切替の前後、53週のある年度、無効な日付・週番、年度をまたぐTSVを確認します。アイコンを作り直す場合は`node scripts/make-icons.mjs`を実行します。
